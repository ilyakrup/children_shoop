# Lille Atelier — Knitwear & Petit 🧸🧶

> Премиальный интернет-магазин детской вязаной одежды и аксессуаров из 100% шерсти мериноса экстрафайн и кашемира в скандинавском минималистичном стиле.

---

## ✨ Особенности проекта

- **Многостраничная архитектура (Multi-Page E-Commerce)**:
  - `index.html` — Главная страница с бренд-стори, лукбуком, гидом по уходу и Covercode-хабом коллекций.
  - `catalog.html` — Полный интерактивный каталог всех коллекций с фильтрацией и сортировкой.
  - `outerwear.html` — Комбинезоны-трансформеры и вязаные пальто.
  - `sweaters.html` — Свитеры, кардиганы крупной вязки с пуговицами из натурального бука.
  - `rompers.html` — Анатомические ромперы и бесшовные штанишки.
  - `blankets.html` — Пледы и конверты на выписку из натуральной шерсти.
  - `shoes.html` — Мягкие пинетки и первые шерстяные мокасины.
  - `sets.html` — Подарочные комплекты и боксы на выписку.
  - `accessories.html` — Анатомические чепчики, варежки и снуды.

- **Скандинавский минимализм & Дизайн**:
  - Теплая натуральная цветовая гамма (молочный, овсяный, графит, песочный).
  - Типографика на основе Cormorant Garamond и Montserrat.
  - Плавные водопадные каскадные анимации появления карточек сверху вниз (`cardCascadeDown`).
  - Scroll Reveal при скролле страницы.

- **Интерактивный функционал**:
  - 🔍 **Живой поиск товаров** как на десктопе, так и в адаптивной мобильной шторке.
  - 📏 **Интерактивный фильтр по размерам** (0-3 мес, 3-6 мес, 6-12 мес, 1-2 года и др.).
  - 👁️ **Быстрый просмотр** (Quick View Floating Modal) без ухода со страницы.
  - 🛍️ **Выдвижная корзина** (Slide-Over Drawer) с расчетом бесплатной доставки и сохранением в `localStorage`.
  - 💖 **Список избранного** (Wishlist) с сохранением состояния.
  - 📐 **Модальное окно с таблицей размеров** (Size Guide).
  - 📦 **Форма быстрого оформления заказа** (Checkout Modal) с валидацией и уведомлениями.

- **100% Mobile Responsive**:
  - Полная адаптация под любые экраны: от ультракомпактных смартфонов (320px–375px) до планшетов и 4K-мониторов.
  - Боковое меню-шторка (`#mobileNav`) для смартфонов и планшетов.
  - Сенсорные горизонтальные свайп-панели для фильтров и категорий.

## 🚀 Запуск проекта

Проект не требует сборщиков и работает на чистом современном HTML5, CSS3 и Vanilla JavaScript:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ilyakrup/children_shoop.git
   ```
2. Откройте `index.html` в любом современном браузере или запустите локальный сервер (например, с помощью VS Code Live Server или `npx serve`).

## Telegram Mini App

Каталог подготовлен для запуска в Telegram через бота [@LilleAtelierbot](https://t.me/LilleAtelierbot/catalog). Кнопка на сайте ведёт по прямой ссылке `https://t.me/LilleAtelierbot/catalog`, а `catalog.html` подключает Telegram Web Apps SDK и учитывает безопасные зоны интерфейса Telegram.

Перед запуском разместите сайт на HTTPS-домене, затем в **@BotFather** откройте настройки `@LilleAtelierbot` и задайте адрес `https://ваш-домен/catalog.html` как Main Mini App. После этого та же ссылка откроет каталог прямо внутри Telegram.
